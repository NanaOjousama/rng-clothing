# Garment Grammar V4.1 — Codex consultation integration

Status: experimental; disabled for production.

This revision folds the consultation recommendations into the V4 model without replacing the frozen V5/HD backend.

## Adopted

- V3 canonical garment model remains the garment brain.
- Frozen V5/HD remains the proven raster/art backend.
- V4 replaces the fragile middle translation layer.
- Per-cell ownership ledger records component owner, system, topology role, semantic region, shade authority, protection level, later mutation permissions, and originating stage.
- Frozen legacy polish runs through an ownership-aware clone/merge wrapper after component identity. Structural overwrite attempts are rejected and traced instead of silently merged.
- A separate bounded topology API now exists for future validated alpha additions/removals. It is not production-enabled until per-direction safe-envelope masks are proven against Farmer/runtime fixtures.
- Visual-change contracts distinguish topology fixes from recolors.
- Identity salience minimums are now validated for Polo and Sailor; existing vest side-armhole structural checks remain.
- Fit variants are normalized separately from topology families through the migration map.
- Named one-off cleanup branches are forbidden in the V4 shape-variant contract.
- Palette modernization remains a later phase. Independent secondary ramps must land before perceptual-space migration.

## Next implementation step

Do not expand families or palette yet.

Build the first renderer-facing V4 shape library for exactly three failure-sensitive structures:
1. Polo folded collar + short front-only placket.
2. Sweater-vest cut-in armhole + inner-layer exposure.
3. Sailor broad collar + mandatory rear panel.

Each variant must define stable ID, directional attachment, bounded footprint, minimum identity cells, shade hints, connectivity, degradation order, and later-stage mutation policy. Use the new topology API only where a validated safe envelope proves alpha edits are safe.

Then render Farmer-scale controlled proofs. A garment that does not read correctly without its label fails human review even if all static validators pass.
