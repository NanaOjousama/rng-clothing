# Hat Renderer V1 — Frozen Architecture

**Decision:** freeze the renderer, not the catalog.

`HAT_RENDERER_V1` is the permanent V1 hat rendering architecture:
- quality baseline: `HAT_PRODUCTION_GOLDEN_V1`;
- production renderer: source-respecting golden state/palette selection;
- native hybrid layer: bounded pattern/region/motif/facing-scope enhancements;
- capacity/taste/exclusion rules remain authoritative;
- failed hybrid safety gates return exact golden/source-respecting pixels.

The existing 20-family batch is a baseline, **not a closed catalog**.
New families may be added without redesigning the renderer.

## New-family protocol

A new hat construction must add:
1. an approved source or authored construction with four directional states;
2. source-respecting locked/mutable feature semantics;
3. family capacity, taste policy, exclusions, and rarity behavior;
4. region semantics for the native hybrid layer where useful;
5. approved golden state/palette pairs;
6. contact-sheet review, then worn/in-game QC.

Ordinary catalog growth must use `HAT_RENDERER_V1`.
A renderer-architecture change requires an explicit renderer-version bump and human approval.
