# Trucker front hybrid test — SF0 + SF1

Purpose: explore the user's requested front-visor target between Sprite Fusion reference hat 0 and hat 1.

Target:
- keep more of SF0's visor body/fullness;
- move the front-view curve/read closer to SF1;
- do not become as flat as SF1;
- keep the visor tucked close to the crown so the view stays straight-on rather than reading as a higher camera angle;
- improve through taper, shallow curve, lower-edge inset, and crown-to-visor join, not through extra projection.

`style_reference/` contains the main nine-candidate 32x32 batch H0-H8. `TRUCKER_FRONT_HYBRID_0_1_BATCH_X8.png` shows SF0, SF1 and all nine hybrids. `TRUCKER_FRONT_HYBRID_0_1_VISOR_CROP_X12.png` enlarges the visor area for shape comparison.

An earlier targeted edit pass is retained in the experiment root for provenance, but it returned only two variably trimmed outputs and is not the main comparison batch.
