# RNG Clothing V2 debug-command source

This is source for a test-only SMAPI helper. It is deliberately separate from the V2 Content Patcher pack and is not part of the clothing generator or any production architecture.

It is compiled directly against the installed Stardew Valley 1.6.15 and SMAPI assemblies. The distributable mod is written to:

`test-packs/vanilla/RNG-Clothing-V2-DebugCommands/`

The helper must never be copied into TFWR or promoted into a production mod.
