# Beanie V1 Source Selection — 2026-09-19

## Decision

Beanie is a NEW family direction and does not inherit the current authored `knit_cap` silhouette as its visual target.

### V1-A — Cuffed Beanie
- Source pack: = RURAL OUTFITTERS =
- Source appearance: Beanie
- Source path: generator content/Rural Outfitters/Rural Outfitters/Hats/Beanie/
- Native frame: 20x20
- Directions: authored Front / Right / Left / Back
- Selected role: PRIMARY BEANIE CONSTRUCTION
- Reason: larger, fuller silhouette than the 16x16 plurffle beanies; full four-direction authored source; enough crown/cuff area to support readable material and motif work.

### V1-B — Slouch Beanie
- Source pack: More Accessories and Stuff
- Source appearance: Beanie (Floppy)
- Source path: generator content/[FS] More Accessories and Stuff Pack/Hats/BeanieFloppy/
- Native frame: 16x16
- Directions: Front / Right / Back with mirrored Left
- Selected role: SECONDARY SLOUCH CONSTRUCTION
- Reason: genuinely different tall/asymmetric slouch silhouette; fuller than the near-duplicate Alt-Fashion Floppy version.

## Reviewed but not selected
- Alt-Fashion Set / Beanie — near-duplicate small 16x16 plain construction; weaker/fullness lower than Rural.
- More Accessories and Stuff / Beanie — near-duplicate small 16x16 plain construction; useful reference, not V1 base.
- Alt-Fashion Set / Beanie (Floppy) — near-duplicate slouch construction; More Accessories version chosen as the stronger/full-bodied authority.
- Beanie (Cat) / Beanie (Bunny) — novelty constructions; defer until the core Beanie family is visually strong.

## Guardrails
- Do not rename/repackage the old authored knit_cap as Beanie.
- Do not add cat/bunny novelty before the plain Cuffed + Slouch silhouettes pass normal-scale live visual QC.
- Source art remains read-only authority; generator-authored semantic zones/materials/motifs are derived separately.
