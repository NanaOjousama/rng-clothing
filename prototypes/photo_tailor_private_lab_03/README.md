# Photo Tailor Private Lab 03 — Hybrid

Disposable private prototype using the same 20-reference challenge set as Lab 02.

Architecture:
- copied golden/source-respecting pixels remain the rendering authority;
- Photo Tailor-style systems may add only bounded feature deltas;
- normalized patterns, region palettes/color bands, motif/facing scopes, overlays and occupancy cleanup are retained;
- source alpha and outline pixels remain untouched.

Primary outputs:
- experiments/photo_tailor_private_lab_03/LAB03_ALL_20_CONTACT.png
- LAB03_HATS_16_CONTACT.png
- LAB03_SHIRTS_4_CONTACT.png
- LAB03_SCORECARD.png

Human visual review remains authoritative over automated proxy scores.
